# Indian Startup Funding Analysis (2020–2025)

## Overview

This project analyzes Indian startup funding trends from 2020–2025 using PostgreSQL, SQL, and Tableau. The objective was to uncover sector-wise, city-wise, and investment-stage funding patterns across the Indian startup ecosystem.

The project involved:
- Data cleaning and validation
- SQL-driven exploratory data analysis
- Business intelligence dashboard creation
- Trend analysis and funding visualization

---

## Tech Stack

- PostgreSQL
- SQL
- Tableau
- Python
- Pandas

---

## Project Workflow

1. Collected and cleaned startup funding dataset
2. Imported processed data into PostgreSQL
3. Performed SQL-based exploratory data analysis
4. Built Tableau dashboards for visualization
5. Generated insights on startup funding trends

---

## Key Features

- SQL-driven funding analysis
- Sector-wise and city-wise trend analysis
- Investment type distribution analysis
- Data cleaning and validation workflows
- Interactive Tableau dashboard
- Funding trend visualization

---

## Key Insights

- Bengaluru emerged as one of the leading startup hubs by total funding raised.
- FinTech and AI-related sectors attracted significant investments.
- Seed and Series A rounds dominated startup funding activity.
- Funding activity showed strong post-2022 growth trends.
- Investor participation increased across multiple startup sectors.

---

## SQL Analysis Performed

- Year-wise funding trend analysis
- Top funded industries
- Top startup cities
- Most active investors
- Investment type distribution
- Startup count by industry
- Funding trend by investment stage
